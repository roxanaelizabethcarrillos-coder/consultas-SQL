# Proyecto: Sistema de Gestión de Alojamientos (Guía de Consultas SQL)

Este repositorio contiene la solución completa de la guía práctica de 20 consultas SQL diseñadas para la gestión y análisis de una base de datos turística.

## 🚀 Motor de Base de Datos Utilizado
* **Motor:** PostgreSQL
* **Entorno de Desarrollo:** pgAdmin 4
